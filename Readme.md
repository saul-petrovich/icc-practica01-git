##¿Qué diferencia existe entre un repositorio local y un repositorio remoto?
	El repositorio local es más rápido y el remoto más eficiente pero lento
##¿Qué esperan que ocurra cuando ambos integrantes modifican archivos distintos?
	que ambos tengamos distintas versiones de los archivos
##¿Qué esperan que ocurra cuando ambos modifican exactamente la misma línea?
	Se almacena la versión del último que la modificó
